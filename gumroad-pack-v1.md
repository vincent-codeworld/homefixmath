## Page outline (6–8 pages)

| # | Page | Contents |
| --- | --- | --- |
| 1 | Cover | Title, one-line value prop, “US feet · prefab panels”, HomeFixMath branding, “Estimates only / not engineering advice” |
| 2 | How to use | 5 steps: measure run → note gates/corners → fill sheet → add 5–10% waste → shop. Link to free online calculator URL (placeholder until domain live) |
| 3 | Measure worksheet | Fields: total run (ft), panel width (4/6/8), gate count & widths, corner/extra posts, height/style notes, call-811 checkbox |
| 4 | Cut list / order sheet | Columns: Item · Spec · Qty calc · Qty to buy · Notes. Prefill rows: Panels, Posts, Caps, Concrete bags (blank qty), Gate kits, Fasteners, Gravel |
| 5 | Layout sketch | Simple blank plan view (rectangle + gate marks) + “last bay may be trimmed” callout |
| 6 | Store checklist | Checkbox list: panels, posts, caps, mix, gate hardware, level, post hole digger / auger rental, string line, PPE. Notes column for Home Depot vs Lowe’s aisle/price (user-filled) |
| 7 | Install day checklist | Optional short list: 811 done, utilities marked, frost-line note, brace gates, stain/seal timing |
| 8 | Back matter | Disclaimer, copyright, “more calculators at [domain]”, optional Gumroad support email |

Keep language **US English**, plain DIY tone, no fake brand endorsements.

## Formula block (same as web calculator — for transparency)

Include a one-box “math used” on page 3 or 4:

1. Net panel length = total run − Σ gate widths  
2. Panels = ceil(net ÷ panel width)  
3. Posts = panels + 1 + (2 × gates) + extra posts  
4. Caps = posts (if using caps)

State clearly: concrete bag counts are **not** calculated in v1 — leave blank for user/pro.
