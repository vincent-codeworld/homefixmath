How we count

  • Length is the direction the boards run. Width is how many boards sit side by side.
  • Boards across the width satisfy n × board width + (n − 1) × gap ≥ deck width.
  • If a stock board is shorter than the deck, each row uses more than one board. Plan seams so they land on a joist. This calculator does not lay out joists.
  • Waste is a percentage on top of the fitted count, then rounded up.
  • Railings, stairs, and picture-frame borders are not included. See the estimate disclaimer.
